## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png` (1024×1024 PNG, 106,142 bytes).
`draw.py` regenerates `entry.png` from scratch with Pillow — every picture
in it is original vector-style artwork drawn by the script, no photographs.
